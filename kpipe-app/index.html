GitHub のトークン

    
「細かく権限を決めるトークン（fine-grained personal access token）」を作って貼ってください。

    
    
      
  1. トークン作成ページを開く
    2. 
      
  2. 「Repository access」で「Only select repositories」を選び、koseiyuki-auto だけを選ぶ
    3. 
      
  3. 「Repository permissions」で次の3つを「Read and write」にする：Actions（動かす）／Contents（台本・結果の読み書き）／Issues
    4. 
      
  4. 有効期限は長めに（切れたら作り直して貼り直す）
    5. 
    

    
    
    
    
    
    

      
      
    

    

    
トークンはこのスマホのブラウザの中だけに保存します。
