設定

  

    
GitHub のトークン

    
kpipe のアプリと共通です。kpipe のアプリで保存したトークンがあれば、そのまま使えます（ここで変えると kpipe のアプリの側も変わります）。

    
    
      
  1. トークン作成ページを開く
    2. 
      
  2. 「Repository access」で「Only select repositories」を選び、koseiyuki-auto だけを選ぶ
    3. 
      
  3. 「Repository permissions」で次の3つを「Read and write」にする：Actions（動かす）／Contents（原稿・結果の読み書き）／Issues
    4. 
      
  4. 有効期限は長めに（切れたら作り直して貼り直す）
    5. 
    

    
    
    
    
    
    

      
      
    

    

    
トークンはこのスマホのブラウザの中だけに保存します。

  


  

    
文字の大きさ

    

      
      
      
    

    
本文の欄は、各画面の「文字 小／大」でさらに変えられます。

  


  

    
X に投稿するには

    
「X に本文を投稿」「リンクを返信」は GitHub Actions が X API で行います。リポジトリの Settings → Secrets and variables → Actions に、X の鍵を4つ入れておいてください：X_API_KEY／X_API_SECRET／X_ACCESS_TOKEN／X_ACCESS_TOKEN_SECRET（PC の _auth/.credentials.txt にあるものと同じ値）。

    
原稿書き（ANTHROPIC_API_KEY）、アイキャッチ（OPENAI_API_KEY）、WordPress（WP_APP_PWD）も Secrets の鍵を使います。

  


  

    
そのほか

    
    
重い処理はすべて GitHub Actions（workflow kpipe-remote.yml）が行います。このアプリは頼んで、結果を読むだけです。原稿の直しの保存だけは、このアプリが GitHub に直接書き込みます。
